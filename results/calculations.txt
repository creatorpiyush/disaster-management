  BLOCK DIAGRAM — SIGNAL CHAINS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Analog emergency radio (required)
      Voice / siren source + pre-emphasis → AM / FM modulator (μ, β = Δf/fm) → RF
      power amp + ridge-top VHF mast → CHANNEL ridge diffraction + static (AWGN) → RF
      front end + limiter → Discriminator / envelope det. → speaker
  Digital mobile network (required)
      ADC + PCM fs ≥ 2W, n bits Rb = n·fs → Channel coding + BPSK / QPSK modulator →
      Hill-top site (eNB / gNB) fibre on roads → CHANNEL Hata + terrain + AWGN → Phone
      RF + demodulator → Decoder + DAC → voice / data
  Satellite backup (required)
      VSAT encoder + QPSK mod. → Up-converter + HPA + dish (uplink fu) → Satellite
      transponder LNA → shift → HPA → CHANNEL FSPL + rain fade + skyline → Dish + LNB
      (downlink fd) → Demodulator + decoder → shelter / EOC
  UAV aerial base station (optional)
      Core link via satellite backhaul → Small-cell baseband (LTE) → Drone-borne
      antenna (altitude h) → CHANNEL air-to-ground over valleys → Phone RF +
      demodulator → Decoder → voice / data
  LoRa / D2D mesh (optional)
      Phone / LoRa node: SOS text → CSS LoRa modulator (SF, BW) → Neighbour relays
      (multi-hop) → CHANNEL ridge-blocked links + ALOHA → Gateway at shelter →
      Satellite uplink → EOC
    Failover order for two-way traffic: Digital mobile network → UAV cell (optional)
    → Satellite backup → LoRa / D2D mesh (optional). The analog emergency radio
    broadcasts alerts throughout.

  LAYER 1 · ANALOG EMERGENCY RADIO (AM / FM)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    when everything else is down.

  LAYER 2 · DIGITAL MOBILE NETWORK
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    Role in the hybrid design: the everyday two-way voice/data network. In Gangtok
    the hill-top sites themselves usually survive, but their fibre and power run
    along roads that landslides cut, so whole sites go off-air; and the network
    saturates when everyone calls at once.

  LAYER 3 · SATELLITE BACKUP
